# Ressarcimento-CAT

Scripts em **Python** para gerar e validar arquivos `.txt` conforme os requisitos da **Portaria CAT-42/2018** da **SEFAZ-SP**, destinados ao ressarcimento fiscal (ICMS-ST/antecipado).

---

## Funcionalidades

- Geração de arquivos `.txt` seguindo o leiaute oficial da Portaria CAT-42.
- Pré-validação dos arquivos com regras tributárias e sintaxe.
- Flexibilidade para inclusão contínua de novas regras tributárias.
- Adaptação facilitada para clientes distintos com requisitos específicos.

---

## Tecnologias

- **Linguagem:** Python
- Estrutura modular e legível para facilitar manutenção e expansão.
